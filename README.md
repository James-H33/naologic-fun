# NaologicWorkorders

Project's main purpose was to build a Gantt view that has similar functionality as found in a custom Gantt Library.
- Create, Edit and Delete Work Order or Work Centers
- Websocket updates for when a Work Order is changed
- Drag and Drop Work Order to change their assigned dates
